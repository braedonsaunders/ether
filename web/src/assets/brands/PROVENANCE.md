# Brand marks

Local copies only. The app does not fetch logos at runtime.

Each SVG is the path geometry from [Simple Icons](https://github.com/simple-icons/simple-icons) v11.14.0, which publishes these marks under [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/11.14.0/LICENSE.md). Retrieved 2026-10-30 from `https://raw.githubusercontent.com/simple-icons/simple-icons/11.14.0/icons/<slug>.svg`.

Sanitized on that date: XML declaration, titles, roles, and every element other than one `viewBox="0 0 24 24"` root and its `path` data were removed. Fill is `currentColor`. No scripts, external references, or event handlers.
