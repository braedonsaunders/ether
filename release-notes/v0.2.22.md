Import TRaSH Guides quality profiles and choose the user and group that own your Docker data.

## Major changes

- **TRaSH Guides profiles:** import quality profiles from the quality-profile page or release console instead of recreating their rules manually.
- **Docker file permissions:** run Ether with your chosen `PUID` and `PGID` so configuration and cache files use the intended host user and group.
- **Plex account recovery:** unclaiming releases the corresponding plex.tv device, and rejected credentials are surfaced instead of silently appearing valid.

**Full changes:** [v0.2.22 commit comparison](https://github.com/braedonsaunders/ether/compare/v0.2.21...v0.2.22).
