Ether v0.2.14 fixes library sharing through Plex.

- Registers Movies, TV Shows, and configured libraries with Plex’s account directory so they appear in Manage Library Access.
- Keeps the published library IDs and names aligned with the server across registration refreshes.
- Preserves the existing Plex server identity and access grants; no re-claim is needed.

Includes the macOS desktop DMG, Windows desktop installer, Linux packages, and signed update manifests.
