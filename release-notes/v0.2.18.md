Ether v0.2.18 adds Stremio stream addon indexers and improves debrid cache decisions.

- Add an approved Stremio addon install URL from Sources › Indexers. Addon access policies still apply.
- Use cached and uncached hints supplied by supported addons when selecting releases.
- Treat Real-Debrid provider-blocked files as unavailable on that account rather than continuing to promote stale cached results.
- Back off new Real-Debrid torrent additions after repeated refusals, starting at two minutes and capped at fifteen.

Includes the native macOS desktop app, Windows installer, Linux packages, and signed update manifests.

Also fixes a Library Visibility loading race that could discard a newly added exclusion group. v0.2.17 was held back by CI and was not published.
