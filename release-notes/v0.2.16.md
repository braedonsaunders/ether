Ether v0.2.16 fixes watch-history imports for shared Plex viewers.

- Uses owner-authorized account discovery and detailed history reads, scoped to the selected viewer.
- Continues reading watched-library state with each viewer’s own access token.
- Filters out other accounts’ history and keeps repeated imports idempotent.
- Includes the v0.2.14 Plex library-sharing fix.

Also updates golang.org/x/net to v0.62.0 and golang.org/x/crypto to v0.58.0, resolving the reachable HTML-parser vulnerability GO-2026-6860.

Includes macOS and Windows desktop installers, Linux packages, and signed update feeds.
