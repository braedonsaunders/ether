Ether v0.2.30 protects existing router mappings and improves recovery from database errors.

- Refuse automatic forwarding over another service’s known router mapping, including a different port on the same host. Preserve mappings reassigned to another service when Ether shuts down.
- Keep valid season ratings when optional episode-rating reads fail, discarding incomplete episode data.
- Roll back incomplete person-credit writes and allow a later browse to retry, instead of suppressing retries for a day.
- Make partial database-read warnings visible at the normal log level and identify the affected cache operation.
- Retry remembered unavailable titles with a fresh search after five minutes when cached-only is off; retain retry evidence across cache cleanup.
- Add a warning and portable regression coverage for directory-sync failures after config renames, preserving consistency between memory and disk.
- Parse addon torrent hashes from recognized fields and resolver routes, avoiding credential-like URL values; clarify that opaque direct/proxied addon links alone are unsupported.
- Detect corrupt stored indexer sessions and report watchlist read failures instead of returning an empty successful response.
- Bound TRaSH custom-format import work in waves while keeping profile imports concurrent.
- Add fault-injection coverage for catalogue cursors, credit rollback/retry and backup-export errors.
