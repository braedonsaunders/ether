Ether 0.2.10 adds automatic RTX Video runtime setup and improves streaming reliability.

- On compatible Windows x64 RTX systems, enabling RTX Video downloads and verifies the pinned NVEncC 9.38 runtime automatically. Setup runs in the background; ordinary transcoding remains available. RTX Video remains off by default, and custom executable paths are respected.
- Added an explicit origin allowlist for embedding the admin interface in dashboards such as Organizr. Embedding remains denied by default; authentication protections are unchanged.
- Fixed duplicate storage of repaired article spans, false cancellation errors during shared fetches, and speculative fetches outliving their readers.
- Corrected Blu-ray M2TS stream alignment and expanded TRaSH language-format imports.
- Plex compatibility reporting now defaults to the verified PMS version. Tracking the newest public version is an explicit opt-in.
- Consolidated shared request coalescing, cache, and Retry-After handling.

Includes macOS DMG, Windows installer, Linux packages, and signed updater manifests. NVIDIA drivers must already be installed for RTX Video. Runtime enhancement is initially limited to the documented supported SDR H.264 HLS/DASH paths.
