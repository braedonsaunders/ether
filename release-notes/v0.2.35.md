Ether v0.2.35 adds configurable movie availability and new collection sources, repairs collection sorting and concurrent edits, and fixes secure connection publication after reclaim.

- Sources → Availability → Settings now offers **Require movie release evidence** and a **Movie evidence window** from 1–366 days. Existing and new installations default to enabled, 60 days. An eligible observed release makes a movie visible immediately; the window is not a mandatory delay. Disabling the movie requirement leaves the episode 24-hour rule and ordinary release-date visibility unchanged. Previously pruned evidence cannot be reconstructed automatically.
- Build collections from public AniList anime lists and Steven Lu popular-movie feeds. AniList list errors are not cached as success, later-page failures are reported, and very large lists carry an explicit truncation warning. Mapping is for collection titles, not episode numbering (#76, consolidating #78/#79).
- Protect indexer and Cardigann fetches against private destinations except the exact owner-configured LAN origin. Direct connections retry the validated addresses before sending a request; public targets remain bound to validated IPs; configured HTTP proxy routes are retained, and TLS pools remain isolated by hostname and IP. Unsupported wrapped transports, non-HTTP proxy schemes and proxy request trailers are refused explicitly (#77).
- Keep Live TV session lookups and failover responsive during I/O, cancel cooperative work when stopped, and serialize concurrent failovers while retaining the earlier startup cancellation repair (#71).

- Select compatible subtitle ZIP entries across SRT/VTT/ASS/SSA formats, skip macOS archive junk, honor forced/SDH filename hints and enforce expansion budgets even on corrupt entries. Unlabelled entries still rely on provider metadata (#80).
- Hydrate duplicate catalogue entries once per occurrence, preserve full genre facets and bound separate hydration/visibility/air-count queries. Crowd selection is stable across input order. The existing combined browse-filter parameter limit remains (#81).

- Populate latest aired episode and season premiere dates for cold collection previews and saved builds. All four sort choices now use fetched and cached regular-season dates, with missing dates last and explicit warnings when dates or provider candidates are incomplete (#83). Requests are bounded; large collections can need more than one evaluation.
- Keep collection results consistent across preview, save and concurrent edits; refresh personal-sort membership, use the same random seed for previews and saved collections, and report partial Trakt, Letterboxd and TMDB pages. Blank provider regions now show the configured default clearly. Existing random collections receive a new order on their next rebuild.
- Publish generated plex.direct HTTPS addresses in Required mode with HTTPS enforcement, and reject empty publication sets (#84). Reclaim marks managed certificates for reissue, keeps the existing certificate during retry, and persists retry state across restart; custom certificates remain untouched (#85). Diagnostics show the last successfully published addresses and distinguish expiry from trust or association. These changes have offline lifecycle coverage; no live account was re-claimed for testing.

The Plex secure-connection report (#42), AIOStreams retest (#21), anime episode numbering, wrong-media/audio reports remain unresolved. The empty subtitle search recovered after a reporter restart; its cause is still unknown.
