The owner console gains 20 languages and per-viewer Simkl history integration, with fixes for notification setup and CSV import selection.

## Changes

- Choose from 20 languages in the owner console.
- Connect individual viewers to Simkl to import watched history and export completed playback.
- Fix notification channel creation over HTTP.
- Keep the selected viewer when the CSV import viewer list finishes loading.

Simkl requires owner-supplied AUTH V2 app credentials and has not been tested with a live account. Anime episodes, rewatches and deletion propagation are unsupported; original-only history omits synthesized bulk-completion dates. A database enqueue failure can lose a completion event. Simkl's authentication overview and device endpoint documentation disagree about PKCE parameters; Ether follows the endpoint-specific schema. Some server-provided text may remain English.
