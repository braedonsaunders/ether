This release adds Profilarr (Dictionarry) quality profile and custom format import (#128) and opt-in per-viewer Plex account watch-state and rating sync (#143).

## Profilarr (Dictionarry) Quality Profile Import

- **Profilarr / Dictionarry quality profile import:** **Releases → Quality** now includes **Profilarr (Dictionarry)** alongside **TRaSH Guides** and **JSON file / paste** as an import source, compiling Dictionarry's `v2` database operations into Radarr and Sonarr quality profiles (`2160p Remux`, `2160p Quality`, `2160p Balanced`, `1080p Remux`, `1080p Quality`, `1080p Quality HDR`, `1080p Balanced`, `1080p Efficient`, `1080p Transparent`, `720p Quality`, and `SD Quality`) with custom formats, scores, regex rules, and language conditions (#128).

## Plex Account Watch-State Sync

- **Per-viewer opt-in Plex watch-state and rating sync:** each viewer can connect their own Plex account under **Viewers → Access** and enable future sync to publish watched/unwatched marks and 1–5 star ratings to `scrobbles.plex.tv`, with manual **Import** and **Export** controls for existing history (#143).
- **Local playback remains authoritative:** sync delivery is asynchronous, bounded, and fenced per viewer so neither a Plex outage nor an unmapped GUID delays or blocks local playback, and guest accounts cannot bind the server owner's Plex token (#143).
