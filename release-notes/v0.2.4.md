Ether 0.2.4 brings the combined playback, transcoding, cache, native archive, and owner-workspace improvements into one desktop release.

### Playback and transcoding

- Keep supported hardware decode, scaling, and encode stages on GPU surfaces; bound software encoder resources.
- Add opt-in server-side NVIDIA RTX Video Super Resolution through NVEnc/NGX on supported native Windows NVIDIA systems. Requires a separately installed compatible NVEnc runtime. Defaults off, with eligibility checks, concurrency limits, ordinary adaptive lower renditions, and explicit fallback.
- Respond promptly to player HLS/DASH rendition changes, preserve audio/video continuity across seeks and switches, and honor native Plex quality/track changes at the same playback offset.
- Reuse persisted media probes and keyframe indexes, shorten adaptive DASH segments, improve Windows fragment publication, and reduce cold-start discovery delays.
- Fix Apple TV initialization requests and repeated decoder settings across Matroska source swaps. Resume source-read failover from the player’s latest requested position rather than a failed file-index read.
- Keep segmented-Matroska source swaps in the original video format, including geometry, colour and bit depth. Convert compatible replacements accurately and skip sources that cannot preserve the opened stream, including incompatible Dolby Vision signalling.
- Wait for Matroska chunk writes to finish before publishing them, and retry temporary chunk-read failures without discarding video.
- Place open-GOP HEVC Matroska chunks by video presentation time, preserve previously delivered GOPs during seeks, and repair cross-source splice points before publication.
- Correct HLS fMP4 open-GOP keyframe timestamps and keep compatible restarts aligned with the initialization data players retain. Reject incompatible track clocks instead of publishing mistimed fragments.
- Expand source validation within a bounded concurrency limit after confirmed failures, while preserving quality policy and candidate order.

### Sources, archives, and cache

- Harden native Usenet scheduling, bounded read-ahead reuse, stalled-read recovery, and hybrid source failover.
- Support bounded native decryption for supported encrypted stored RAR/7z archives; this is not general extraction or PAR2 repair.
- Improve obscure-title search and prefer ready cached debrid results.
- Avoid falsely reporting missing archive volumes when an obfuscated post exceeds the initial header-probe limit.
- Add adaptive cache management, household-aware movie and TV preloading, standalone NAS caching, and coordinated shared cache support for clusters.

### Owner experience

- Redesign Collections with a split preview workspace and native poster choices.
- Add a richer Metadata artwork workspace with factual badges and cached poster styles.
- Add guided cluster setup, compact Cache tabs, consolidated Maintenance tools, browser push, and independent crash alerts.
- Make Recommended lists and large show pages avoid repeated season loads; use indexed episode reads and refresh only seasons that need it.
- Refresh the README with nine screenshots and consolidate public installation/user documentation.
- Include token, revocation, forwarded-address, and active-content security hardening.
- Protect newly created data directories and SQLite credentials with owner-only Unix permissions, and apply restrictive Windows ACLs during LocalSystem service installation.
- Build with Go 1.27.3, including the standard-library certificate distrust correction for GO-2026-6809.

### Credentials and backups

- Bind encrypted configuration secrets to their setting and destination; encrypt supported stored integration credentials and remove secret-bearing URLs from cached search results and release-console responses.
- Refuse stored-secret reuse when a provider destination changes, and reject startup when a sealed database cannot be opened with its original credential key.
- Export password-encrypted `.etherbackup` files. Restoring an older plaintext bundle requires an authenticated owner and explicit confirmation.
- Keep Live TV provider URLs and authentication headers out of FFmpeg/FFprobe command lines through a scoped loopback relay for HLS, DASH, and continuous streams.
- Delay the credential-format upgrade until an automatic update is confirmed and compatible cluster nodes are ready. After migration, a manual downgrade requires restoring a matching pre-upgrade backup of the database, configuration, and credential key together; replacing only the executable is insufficient. Keep the credential key with your backups.

### Validation and limits

The combined playback changes passed the Linux pure-Go build, vet and all-package tests, plus focused race tests. Native Windows regression tests verified safe fMP4 file replacement. Genuine RTX enhancement and adaptive fallback were exercised on an RTX 4080 during development. The HDR/geometry contract was verified through real Mac VideoToolbox encoding. Platform CI and installer results are linked from the release commit.

Controlled benchmark results are workload-specific and do not establish universal Plex superiority or sustained maximum concurrency. The Linux comparison used different quality settings and cannot support a like-for-like efficiency claim. The final fMP4 browser impairment test had no post-start waiting; a TS test still stalled briefly. Native-player seamless adaptation is not certified across every client, and segmented Matroska retains its probe safeguard.

Matroska HEVC open-GOP copy splices are verified with FFmpeg; actual Apple TV BLA-keyframe handling still needs client validation. A source swap can lose roughly three leading video frames, and existing encoder restarts can leave an audio gap of about 0.21 seconds. This release does not claim gapless failover for every source.

### Downloads and installation

- **macOS 13+:** `Ether-0.2.4.dmg`, universal Intel + Apple Silicon menu-bar app.
- **Windows x64:** `EtherSetup-0.2.4.exe`, server service and tray launcher. Standalone ARM64 binaries are also available.
- **Linux amd64 / arm64:** DEB, RPM, and standalone archives.
- **Docker:** `ghcr.io/braedonsaunders/ether:0.2.4` (amd64 / arm64).

Open http://localhost:32400/ether/ after starting Ether. Installers and archives bundle FFmpeg and FFprobe 8.1.3.

The macOS app is **ad-hoc signed, not Apple-notarized**. macOS may require System Settings → Privacy & Security → Open Anyway after the first launch attempt. The Windows installer is **not Authenticode-signed** and may trigger SmartScreen. The update manifest is separately signed with Ether’s Ed25519 release key.

Ether ships no content, providers, site definitions, accounts, or third-party API keys. Supply your own TMDB key and service credentials. Ether is not affiliated with Plex or TMDB.
