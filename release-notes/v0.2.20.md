Adds Debrid-Link and Offcloud, supports debrid-only setup, and improves installation, upgrade recovery and playback failure diagnostics.

## Major changes

- **More debrid services:** add Debrid-Link and Offcloud, with service-specific error messages.
- **Debrid-only setup:** complete the wizard without configuring a Usenet provider.
- **Safer upgrades:** snapshot SQLite before pending migrations, upgrade the Windows service in place and wait for shutdown, and restart a server left on the previous version after an app upgrade.
- **Run alongside Plex Media Server:** avoid port conflicts with an existing PMS installation.
- **Playback diagnostics:** return a failure explanation instead of a bare 404. How much of that explanation appears still depends on the Plex client.
- Report owner subscription features to shared Plex clients.
- Remove dependent client rules when their quality profile is deleted, and improve first-run setup guidance.

## Docker upgrade note

This release runs the container as user 999 and corrects the cache location. Check ownership of mounted data directories when upgrading. Configurable `PUID`/`PGID` arrives in v0.2.22.
