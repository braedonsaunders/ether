Ether 0.2.6 improves Plex recommendation stability and browsing performance, especially when the database is on another cluster node.

- Keep recommendation shelves and title order stable when watched state changes.
- Reduce repeated database reads while rendering posters and recommendations.
- Batch catalogue hydration and summary writes while preserving list order, existing details, and release visibility rules.
- Add optional node-local SOCKS5 egress for Usenet connections through `ETHER_USENET_PROXY`. Provider TLS hostname verification remains enabled, and proxy errors do not fall back to a direct connection. See [installation guidance](https://github.com/braedonsaunders/ether/blob/v0.2.6/docs/install.md).

Includes macOS DMG, Windows installer, Linux packages, container images, and signed update manifests. Existing configuration and Plex server identity are preserved.

Validation includes the full Go suite and a temporary Mac/Windows/Linux cluster with real HLS playback on each node, cross-node session visibility, shared playlists, leader handoff, and Plex Web playback. The cluster was subsequently returned to standalone SQLite and playback rechecked. These are functional checks, not a capacity benchmark or a claim of seamless playback migration during a host failure.

Ether ships no content, providers, or indexers. Owners supply their own services and are responsible for what they access.
