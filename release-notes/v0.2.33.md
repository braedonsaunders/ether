Ether v0.2.33 improves Usenet cache writes and diagnostics for source discovery and playback.

- Serialize concurrent NZB cache saves and use unique temporary files, preventing same-release writes from corrupting one another (#45).
- Preserve NNTP missing-article reply codes in errors and health-check explanations (#45).
- Accept explicitly labeled torrent hashes from magnet URLs and addon sources, preserve magnet trackers, and reject conflicting explicit hashes across sources (#50).
- Report addon streams skipped for missing or ambiguous hashes using throttled, host-only messages without logging private playback URLs (#50).
- Surface previously swallowed cache/database write and row-iteration errors across source, playback and Plex components (#51).

The addon diagnostics help investigate #21 and similar reports; this release does not claim universal AIOStreams compatibility or resolve the separate Bleach numbering / wrong-movie reports.
