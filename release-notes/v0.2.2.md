Ether 0.2.2 adds easier language-model setup and live server-load monitoring.

### New

- **Language-model providers:** choose Anthropic, OpenAI, Gemini, OpenRouter, Groq, xAI, DeepSeek, Mistral, Ollama, LM Studio, or a custom OpenAI-compatible server. Search the live model list from your provider, with native Anthropic support.
- **Overview server load:** live CPU, memory, network traffic and available GPU utilisation, with five-minute sparklines and Ether’s own CPU and memory use. GPU readings pause when nobody is viewing the Overview.

### Downloads

- **macOS 13+:** `Ether-0.2.2.dmg`, a universal Intel + Apple Silicon menu-bar app.
- **Windows x64:** `EtherSetup-0.2.2.exe`, with the server service and tray launcher. Standalone Windows ARM64 binaries are also available.
- **Linux amd64 / arm64:** DEB, RPM and standalone archives.
- **Docker:** `ghcr.io/braedonsaunders/ether:0.2.2` (amd64 / arm64).

Open http://localhost:32400/ether/ after starting Ether. Installers and archives bundle FFmpeg and FFprobe 8.1.3.

### Installation

The macOS app is **ad-hoc signed, not Apple-notarized**. macOS may require System Settings → Privacy & Security → Open Anyway after the first launch attempt. The Windows installer is **not Authenticode-signed** and may trigger SmartScreen. The update manifest is separately signed with Ether’s Ed25519 release key.

Ether ships no content, providers, site definitions, accounts or third-party API keys. Supply your own TMDB key and service credentials. Plex and TMDB are independent third-party services; Ether is not affiliated with or endorsed by either.
