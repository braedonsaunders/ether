Recover an existing Ether server after its authorization is removed from your Plex account, without starting setup from scratch.

## Changes

Fixes Plex reconnection after Ether is removed from Plex Authorized Devices.

- The setup wizard now offers **Reconnect** even when it has a saved Plex claim. Sign in with the existing server owner to renew authorization while keeping Ether’s identity and settings.
- Failed sign-in attempts stop waiting and show their error. Failed claims remain retryable, and setup cannot save stale credentials while reconnection is incomplete.
- Existing owner checks remain enforced; signing in as a different Plex account cannot replace the owner through this flow.

For issue #126: open **Connectivity → Reopen setup wizard → Reconnect**, approve the existing owner’s Plex account, and wait for the claim to complete. No configuration wipe or new server identity is needed.

Validated with offline recovery, failure/retry, credential-refresh and owner-isolation regressions, plus the full Go and web suites. The reporter’s live account and separate Plex server remote-access problem were not reproduced.
