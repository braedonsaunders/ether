This release fixes missing owner collection shelves and disappearing genre shelves on Plex Home, restores subtitle and audio stream listings on initial playback queue creation, expands LAN GDM multicast discovery across active network interfaces for Fire TV clients, holds unlabelled `.XviD` / `MPEG-2` scene encodes to profile minimum resolution floors, refills Play Versions candidates when resuming a remembered release, and reduces settings snapshot allocations during availability discovery.

## Plex Home, Playback, and Discovery

- **Keep owner collection shelves and genre rows stable on Plex Home:** owner-authored collection shelves (`RowSourceOwner`) are no longer hidden by the 12-item algorithmic shelf floor, cold-start viewer models inherit the active generic presentation's shelf-count floor so shelves such as `Acclaimed <Genre>` do not vanish when `/hubs/items` expands `count` to 50, `/hubs/items` resolves items against the requesting viewer's layout, and saving or deleting a collection immediately invalidates cached owner shelves (#180).
- **Warm detail metadata before rendering `/playQueues`:** `POST /playQueues` now warms detail metadata for the selected item when not already warm, and paused or stopped playback sessions no longer block detail-page warming, ensuring embedded and external subtitle tracks appear immediately in the Plex Web and Android player OSD (#145).
- **Join GDM multicast across all active LAN interfaces:** `listenGDM` now binds `0.0.0.0` (`IPv4zero`) and joins `239.0.0.250` across every active non-loopback, non-virtual multicast interface so Plex on Fire TV and Android TV discovers Ether reliably on multi-NIC hosts (#181).
- **Refill Play Versions candidates on resumed detail warm-up:** when an admitted detail warm-up reuses a remembered release after a restart or search-cache expiry, Ether now triggers a bounded background search-cache refill so alternative versions remain available in Plex's Play Version menu (#182).

## Release Selection, Collections, and Availability

- **Hold unlabelled `.XviD` and `MPEG-2` releases to minimum resolution floors:** `floorHeight` now treats unlabelled `SourceUnknown` releases with `xvid` or `mpeg2` codecs as 480p so SD `.XviD-AFG` releases cannot bypass a 720p or 1080p profile minimum resolution gate (#179).
- **Include TV content ratings in Movie and Mixed collection rule pickers:** the `contentRating` facet picker in the collection rule builder now always includes standard MPAA and US TV ratings (`TV-Y`, `TV-G`, `TV-Y7`, `TV-PG`, `TV-14`, `TV-MA`) even before those ratings are cached in the local TMDB movie facet table.
- **Accept Torznab/Newznab URLs pasted with query parameters:** `apiURL` now parses and normalizes indexer URLs that already contain query parameters (such as copied Jackett feed links with `?apikey=...`) before appending `/api`.
- **Reuse settings snapshots during availability discovery:** availability filtering, prioritization, and newly available shelves now capture a single isolated settings and source snapshot per discovery operation instead of cloning full settings per check (#183).
