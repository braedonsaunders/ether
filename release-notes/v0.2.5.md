Ether 0.2.5 fixes Plex browsing after watch-state changes and fills recommendation shelves.

- Continue Watching now returns correct totalSize, offset and paged items when Plex Web refreshes a shelf. Marking one movie watched removes that movie while retaining the others.
- Generated recommendation shelves require at least twelve relevant titles (all ten for Top 10 rows). Thin shelves are omitted and their titles become available to fuller shelves, including when a generated row is pinned.
- Continue Watching and Up Next still reflect the actual available items; owner collections retain their intended contents.

Validation: both regressions fail before the fixes and pass afterward; focused race checks and the full pure-Go build, vet and test suite pass. Release publication additionally requires CI on this exact commit.

The macOS app is ad-hoc signed, not notarized. The Windows installer is unsigned. Existing settings, server identity and watch history are preserved on upgrade.
