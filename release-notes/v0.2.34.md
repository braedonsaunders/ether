Ether v0.2.34 adds custom poster sources, movie release-window filtering, and owner control over unwanted cached releases.

- Use self-hosted PostersPlus, BetterPosters, Rating Poster Database, or a custom URL template under Metadata → Artwork. Provider failures fall back to TMDB; keys and exported template URLs remain server-side. Movie/show posters support Ether overlays and Plex image resizing. Season, episode and collection artwork retain their existing behavior (#68).
- Optionally wait for a movie’s earliest worldwide digital or physical release. If TMDB has no qualifying date, movies become eligible 90 days after theatrical release and keep that fallback admission after later date corrections. The setting defaults off. Metadata checks run in bounded background batches; this is a catalogue date filter, not a guarantee of release quality (#53).
- Clear and block an unwanted release from the Cache explorer. The block persists even without a known title key and applies to warm/resume selection. Active or paused playback is protected; retained background/shared-cache bytes are reported rather than falsely shown as cleared (#62).
- Preserve existing Prowlarr import IDs while reporting skipped protocols and rate-limit delays (#55).
- Warn once per session when HEVC encoding falls back to H.264, and account for retained download files across restart, including failed deletion attempts (#56, #57).
- Show readable subtitle titles and download times without scanning the selection index. Preserve language preference order and isolate automatic forced/SDH subtitle selections across viewer preferences (#58, #59, #61).
- Reduce repeated language-validation and playlist allocations (#60).
- Validate Premiumize cached availability in the background and avoid unnecessary Debrid-Link account listing on cold playback (#64).
- Fetch ratings for different titles concurrently, with independent cancellation and isolation when provider settings change (#66).
- Prevent a second Ether instance from opening the same data directory, before it can alter startup settings or clean live transcode files (#65).

- Prepare Live TV tracks outside the session lock, cancel cooperative encoder startup when tuning stops, and clean up discarded relay resources (#71).

- Sort collections by latest aired episode or latest season premiere using mirrored regular-episode dates; future episodes and specials are excluded, with unknown dates last (#72).
- Back off Cache page refreshes on errors while keeping the Explorer live and preserving its filter (#74).
- Identify self-signed certificate fallback in server health and distinguish certificate expiry from client trust. This diagnostic does not by itself resolve the secure-connection report (#42).

The reported Plex Web secure-connection failure (#42), AIOStreams playback report (#21), anime numbering mismatch, and wrong-movie report remain under investigation. This release does not claim those reports are resolved.
