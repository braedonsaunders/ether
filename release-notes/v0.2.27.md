# Ether 0.2.27

- Added **Catalog → Settings → Hide automatic franchise collections**. Turn it on to remove automatic TMDB franchise groups (such as Zootopia) from Plex’s Collections tab. Curated collections and Home rows remain independently controlled.
- The setting applies after saving, without restarting Ether. Refresh the Collections tab in Plex to see the change. Turning it off restores the automatic groups; no catalogue data is deleted. Existing installations keep showing these groups by default.
- Includes v0.2.25’s fix for Plex for Linux being incorrectly limited to 1080p by the unknown-client fallback (#22).
