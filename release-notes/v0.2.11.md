Ether 0.2.11 fixes stale Continue Watching metadata after playback.

- Plex clients now receive a library watch-state refresh after an episode or movie completes, and when playback pauses or stops. This includes finishing an episode, briefly autoplaying the next, and returning to the home screen.
- Notifications are sent after watch state is committed, including deferred cluster writes, and retain viewer scoping.
- Ordinary playing heartbeats do not trigger library refreshes, and completion does not send duplicate refresh notifications.

Includes rebuilt macOS DMG, Windows desktop installer, Linux packages, and signed updater manifests. All features and defaults from 0.2.10 are retained, including automatic RTX runtime installation when enabled and RTX Video off by default.
