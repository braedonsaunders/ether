This release adds configurable same-quality alternative releases to Plex's
Play Version menu and eliminates cold account-list waiting during speculative
background checks on TorBox and Debrid-Link.

## Plex Play Versions

- **Offer same-quality alternative releases after Auto:** detail pages now list
  other ranked releases sharing the automatic pick's cut, resolution, and HDR
  type right after Auto in Plex's **Play Version** menu, labelled by quality,
  audio, size, and release group (for example
  `1080p WEB-DL · DD+ 5.1 · 2.3 GB · FLUX`) so viewers can switch releases if
  one fails (#176).
- **Configurable alternative count (`0` to `3`, default `1`):** owners can set
  **Same-quality versions to offer** (`resolver.sameQualityAlternatives`) under
  **Releases → Release selection** in the admin console, raising the shared
  Play Version picker cap (`core.MaxVariants`) from `4` to `7` while preserving
  distinct quality tiers and cuts (#176).

## Debrid and Resolver

- **Non-blocking cold account lists in background checks:** speculative
  background checks on TorBox and Debrid-Link now consult known torrent IDs or
  a fresh one-minute account snapshot and start a single shared read-only
  refresh in the background without blocking, allowing foreground playback to
  proceed immediately while sharing the in-flight snapshot for duplicate
  recovery (#177).
