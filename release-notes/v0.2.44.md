Stremio addons can now supply direct HTTP streams and Usenet NZBs, alongside improvements to anime discovery and language preferences.

## Changes

- Accept direct HTTP playback links and Usenet NZB results from Stremio addons. HTTP streams use the addon’s configured service and do not require a separate Ether debrid account. Temporary addon failures remain retryable.
- Add anime database IDs and absolute episode numbering where an unambiguous mapping is available.
- Improve release-language parsing, including flag labels, regional Spanish and Portuguese, and subtitle-only tags such as VOSTFR. Quality-profile language preferences now recognize ISO codes.
- Show the serving source in Home and Activity: named debrid services, Usenet, or HTTP for addon links.

HTTP playback requires range-capable media responses; playlists and small placeholder clips are not supported. Anime mapping does not supply missing romanized alternative titles. No live DebridIO, AIOStreams or Torrentio account was tested, so the reported DebridIO setup is not confirmed fixed.
