This release fixes pre-play audio and subtitle track selectors across cold
detail-page opens, stopped playback, and TV show/season views on Plex clients
(including NVIDIA Shield / Android TV), fixes embedded text subtitle playback
during remux/transcode sessions, and adds default TRaSH release group custom
formats to quality profile imports.

## Plex Playback and Pre-Play Track Selectors

- **Synchronous detail-page warm-up probe (`WaitWarmProbe`):** opening a movie
  or episode detail page now waits up to a bounded budget (`4s`) for the
  background warm probe (`probeGeneration`) to complete before rendering
  `<Media><Part><Stream>` metadata, so the very first detail-page visit lists
  real embedded audio and subtitle tracks instead of a single estimated track
  (#145).
- **Retain probed tracks on `Auto` across fallback candidates and playback:**
  when `Auto` playback selects a candidate other than `Variants[0]` (because
  the top cached search result was skipped during health or debrid cache
  checks), stopping playback and returning to the detail page now attaches the
  probed tracks to the `Auto` entry (`Media[0]`) instead of dropping all
  `<Stream>` tags (#145).
- **Retain warm-probed tracks across `Prepare` and extended browsing:**
  consuming a warm resolution for playback now preserves its probed `MediaInfo`
  in the warm cache (`60m` TTL, `128` entries, `30/min` detail warm-up budget,
  and automatic replacement of stale in-flight detail warm-ups when navigating
  to a new title), and `ResumedTracks` matches across LAN/WAN remote-cap
  boundaries in Docker bridge setups (#145).
- **TV show `OnDeck` and season episode track warming:** opening a TV show page
  (`includeOnDeck=1`), `/ondeck`, or a season episode list (`/children`) now
  warms the next playable episode (`OnDeck` or first unwatched/in-progress
  episode) and includes its probed `<Stream>` tags in the response (#145).
- **Embedded text subtitles during remux and transcode sessions:** selected
  non-burned embedded text subtitles in remux/transcode decisions now report
  `location="sidecar"` with `key="/library/streams/<id>"` and serve extracted
  WebVTT/SRT cues from `/library/streams/<id>` and
  `/video/:/transcode/universal/subtitles`, instead of reporting
  `location="segments-subtitle"` when FFmpeg runs with `-sn` (#145).

## Quality Profiles and Import

- **TRaSH default release group custom formats:** quality profile imports now
  include built-in TRaSH release group custom formats (`WEB Tier 01/02/03`,
  `HD Bluray Tier 01/02/03`, `UHD Bluray Tier 01/02/03`, `Remux Tier 01/02`,
  `LQ`, `LQ (Release Title)`, `Bad Dual Groups`, `No-RlsGroup`, `Obfuscated`,
  `Retags`, `Scene`) with pre-populated regex rules so imported profiles score
  release groups out of the box (#86, #172 — thanks @evulhotdog!).
