Keeps playback choices stable for Plex for VIDAA clients that cache media-version settings.

## Changes

## Plex for VIDAA compatibility

- Keep one automatic media choice visible to Plex for VIDAA, avoiding version-list changes that can leave its cached playback settings without MediaVersion.
- Automatic source selection and playback quality controls remain available. The separate Play Version picker is unavailable in VIDAA with this compatibility fallback; other Plex apps retain their version choices.

This targets the reproduced settings-cache failure investigated in issue #89. Reporter validation on the affected TV is still pending; other buffering causes remain under investigation.
