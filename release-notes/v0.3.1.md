# Ether 0.3.1

Ether 0.3.1 bundles a built-in TMDB key into all release builds so fresh installs populate a catalogue immediately, fixes **Connect apps** in Docker bridge mode, keeps unreachable Usenet providers marked unhealthy, adds an owner switch for automatic update checks, and enforces a 12-character minimum for new local passwords.

## Highlights

- **Bundled TMDB key and fallback guidance:** Official release binaries, packages, and Docker images now include a built-in TMDB API key (`internal/tmdb.BundledKey`), so a fresh install builds its catalogue out of the box without requiring a separate key. For custom builds without a bundled key, the setup finish screen, **Overview › Next steps**, and **Catalog** now link directly to **Server › Integrations › TMDB**, which includes a direct link to `themoviedb.org/settings/api`.
- **Connect apps in Docker bridge mode and behind reverse proxies:** `/ether/me › Connect apps` now resolves the server address from configured custom/public URLs first, then the browser's `Host` header (or `X-Forwarded-Host` / `X-Forwarded-Proto` from trusted proxies) with the app's port, before falling back to local interface subnet matching. Creating app passwords in Docker bridge mode no longer fails with `503 address unavailable`.
- **Accurate Usenet provider health:** Usenet providers that fail warmup dials or authentication keep their `Needs attention` status and plain-language reason (DNS failure, connection refused, TLS error, timeout, or rejected login) across breaker cooldowns until a probe or connection actually succeeds, instead of reverting to `Healthy · Connected`.
- **12-character minimum for new local passwords:** Setting a new local owner or viewer password in setup, **Sign-in methods**, or **Viewers** now requires at least 12 characters, matching the minimum required for encrypted backup downloads. Existing passwords continue to work unchanged.
- **Automatic update check toggle and `plex.tv` gating:** Owners can turn automatic update checks off under **Server › General › Updates** (`updates.enabled`, on by default). When the Plex app is turned off under **Server › Apps**, Ether now stops background `plex.tv` registration, friend sync, and metadata refreshes even on a previously claimed server.
- **Startup next-step log and documentation improvements:** At startup, Ether logs a single `INFO` line indicating the next setup step when setup, a streaming source, an indexer, or a TMDB key is still missing. Updated `README.md` and `docs/install.md` with a **Things to know first** section, exact outbound network behaviour, consistent port `8096` and Docker Desktop guidance, HTTPS requirements for Stremio, and a log-keyed troubleshooting table.
