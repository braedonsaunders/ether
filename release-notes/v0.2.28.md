# Ether 0.2.28

- Fixed native Plex for Linux, Windows, Mac and Plex Desktop apps inheriting browser-only codec defaults. They now use the existing HTPC capability profile, allowing compatible HEVC Main 10, HDR10, AV1 and VP9 sources to retain their video rather than forcing H.264 conversion.
- Plex Web keeps its browser-specific capabilities. Explicit client resolution and HDR limitations still apply. Actual HDR display output depends on the player, OS and hardware; this change fixes Ether’s server-side defaults (#23).
- Includes **Catalog → Settings → Hide automatic franchise collections** from v0.2.27. Save and refresh Plex’s Collections tab to hide automatic TMDB franchise groups without deleting catalog data.
